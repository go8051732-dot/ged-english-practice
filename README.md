# 중졸 검정고시 영어 기출 연습

GitHub Pages로 제공하는 정적 연습 사이트입니다. `index.html`을 열면 바로 사용할 수 있으며, 풀이 기록은 브라우저에 저장됩니다.

배포: GitHub Pages의 `main` 브랜치, 루트(`/`).

English word definitions include Princeton WordNet 3.0 data. See WORDNET-LICENSE.txt for the license and copyright notice.


## 휴대폰 앱으로 설치하기

이 사이트는 홈 화면에서 앱처럼 실행되는 설치형 웹앱(PWA)으로 제공됩니다. GitHub Pages 주소를 휴대폰에서 열어 설치하세요.

- Android: 페이지의 **앱 설치** 버튼을 누르거나 Chrome 메뉴에서 **앱 설치**를 선택합니다.
- iPhone: Safari에서 **공유 → 홈 화면에 추가**를 선택합니다.

설치 후에는 홈 화면 아이콘으로 열리며, 문제와 저장된 학습 기록은 오프라인에서도 사용할 수 있습니다. 발음 등 외부 사전 조회는 인터넷 연결이 필요합니다.
